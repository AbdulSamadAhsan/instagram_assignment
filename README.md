# Instagram-inspired Authentication UI

React interface exercise with Instagram-inspired login and registration pages.

[Live deployment](https://instagram-assignment-jade.vercel.app)

## Overview

- Login and registration page layouts
- Reusable form, branding, and hero components
- Client-side routing

## Stack

React, Vite.

## Run locally

```bash
git clone https://github.com/AbdulSamadAhsan/instagram_assignment.git
cd instagram_assignment
npm install
```

This is an independent UI exercise, not an official Instagram application. The interface alone does not provide a production authentication service.

```bash
npm run dev
```

Use the local URL printed by the development server.
